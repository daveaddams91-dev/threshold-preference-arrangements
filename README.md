# Threshold Preference Arrangements

[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)
[![CI](https://github.com/rajveersinh-is-dev/threshold-preference-arrangements/actions/workflows/ci.yml/badge.svg)](https://github.com/rajveersinh-is-dev/threshold-preference-arrangements/actions)


Exact chamber counts for tolerance-based distance orderings of point sets (arrangements of indifference hyperbolas)

## Features

- Clean, modern Python 3.10+ implementation.
- Typed signatures and robust error handling.
- Comprehensive unit test coverage.

## Installation & Usage

```bash
git clone https://github.com/rajveersinh-is-dev/threshold-preference-arrangements.git
cd threshold-preference-arrangements
python "examples/four_candidates.py" --help
```

## Testing

```bash
pytest tests/
```
